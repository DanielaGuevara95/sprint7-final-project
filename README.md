# Análisis de Segmentación de Clientes y Datos — ConnectaTel

## 🎯 Objetivo del Proyecto
Analizar la base de datos de ConnectaTel para realizar una segmentación de clientes basada en variables demográficas y de uso (`grupo_edad` y `grupo_uso`). El propósito principal es traducir los hallazgos en conclusiones de negocio accionables y optimizar la estrategia comercial.

## 📊 Datasets Utilizados
* **`users`**: Información demográfica y de registro de los clientes.
* **`usage`**: Métricas de consumo de red (llamadas y mensajes).
* **`user_profile`**: Tabla consolidada tras el cruce y limpieza de las fuentes anteriores.

## ⚙️ Etapas del Análisis
1. **Auditoría y Limpieza:** Corrección de anomalías temporales en la columna `reg_date` y tratamiento de nulos.
2. **Feature Engineering:** Creación de los segmentos `grupo_edad` y `grupo_uso`.
3. **Visualización:** Gráficos de distribución con Matplotlib y Seaborn.
4. **Insight Ejecutivo:** Conclusiones estratégicas orientadas a stakeholders.
